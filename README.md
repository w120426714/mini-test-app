# 心测研究所

Multi-platform Taro mini program for entertainment-first psychological and ability tests.

## Scripts

- `npm run dev:weapp`: WeChat development build with watch mode.
- `npm run dev:alipay`: Alipay development build with watch mode.
- `npm run dev:tt`: ByteDance/Douyin development build with watch mode.
- `npm run build:weapp`: WeChat production build.
- `npm run build:alipay`: Alipay production build.
- `npm run build:tt`: ByteDance/Douyin production build.
- `npm run test`: Run Vitest tests for pure business logic.

## Manual Preview

Open the generated `dist` directory or project directory in the matching platform developer tool according to the platform's requirements.
